# bedrock-scanner

This mod **exports bedrock data to a file** that can be used with 19MisterX98's [Nether_Bedrock_Cracker](https://github.com/19MisterX98/Nether_Bedrock_Cracker) to assist in seed cracking.

## Usage
Go anywhere in the Nether and run the following command:

/bedrockscan `<size>`
- `<size>` specifies the scan size. I recomend using anywhere from 16-32 for this value.
- The command scans the top and bottom layers of bedrock around the player and writes the positions to a file in the `bedrockscanner` folder.
